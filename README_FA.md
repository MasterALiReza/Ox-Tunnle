# 📌 معرفی پروژه

سیستم **Ox Tunnle** یک تانل TCP معکوس مدرن و پیشرفته است که برای اتصال پایدار و سریع دو سرور طراحی شده است:

- 🇮🇷 سرور ایران (IR / سرور ورودی تانل)
- 🌍 سرور خارج (EU / سرور خروجی و مقصد)

این نسخه بر پایه موتور ناهمگام **AsyncIO** (با پشتیبانی از شتاب‌دهنده `uvloop`) بازنویسی شده است که اتلاف منابع سیستم را به صفر رسانده و حتی با وجود هزاران اتصال همزمان، مصرف RAM سرور را زیر ۵۰ مگابایت حفظ می‌کند. همچنین با ادغام پروتکل امنیتی **HMAC-SHA256 Challenge-Response**، سرورهای شما در برابر اسکنرهای فعال، حملات Replay و اتصال اشخاص ثالث کاملاً محافظت می‌شوند.

---

# 🧠 معماری سیستم

```
کاربر → سرور IR (0.0.0.0:Port) ⇄ [کانال امن با HMAC] ⇄ سرور EU → سرویس داخلی (127.0.0.1:Port)
                                  │
                        Bridge Port (پورت اصلی ترافیک)
                                  │
                         Sync Port (همگام‌سازی هوشمند)
```

### 🔹 Bridge Port
پورت اصلی انتقال پایدار داده‌ها بین سرور ایران و خارج، محافظت‌شده توسط توکن‌های احراز هویت رمزنگاری‌شده HMAC.

### 🔹 Sync Port
کانال سریع و کم‌تغییر برای همگام‌سازی و اعلام پورت‌های باز سرور خارج به سرور ایران در ساختار AutoSync.

# 🛠 قابلیت‌ها و مزایای فنی

| قابلیت | توضیح |
| :--- | :--- |
| **موتور قدرتمند AsyncIO** | معماری مدرن رویداد-محور (Event-Driven) با کمترین مصرف پردازنده و رم همراه با پشتیبانی از `uvloop` |
| **امنیت لایه ۴ (HMAC-SHA256)** | پروتکل Challenge-Response برای مسدودسازی آنی اسکنرها، حملات Replay و تلاش برای دسترسی غیرمجاز |
| **Reverse TCP Tunnel** | اتصال دوطرفه و فوق‌پایدار از سرور خارج به سرور ایران جهت عبور از محدودیت‌ها و اختلالات شبکه |
| **Multi-Slot (1–10)** | ذخیره‌سازی تا ۱۰ پروفایل تانل مجزا روی یک سرور (`eu1`, `ir1`, ...) |
| **AutoSync هوشمند** | تشخیص خودکار پورت‌های باز روی سرور خارج و باز کردن خودکار آن‌ها روی سرور ایران |
| **یکپارچگی استاندارد با Systemd** | اجرای دائم به عنوان سرویس‌های الگو (`ox-tunnle@.service`) و بازگشت خودکار سرویس‌ها پس از ریبوت سرور |
| **Cron Health Check** | بررسی‌کننده خودکار سلامت سرویس‌ها با قابلیت استارت دوباره در صورت بروز خطا |
| **بهینه‌سازی شبکه (BBR)** | تیونینگ پارامترهای کرنل لینوکس و فعال‌سازی אלگوریتم BBR جهت حداکثر کردن پایداری و سرعت |
| **خاموش‌شدن تمیز (Graceful Shutdown)** | مدیریت ایمن سیگنال‌های سیستم و بستن بدون خطا و نشت پورت‌های سوکت در پس‌زمینه |
| **لاگ‌های زنده و بهینه** | مشاهده لاگ‌های سیستم بدون تاخیر از طریق `journalctl` یا سیستم چرخش لاگ متوقف‌نشدنی |

# 🟢 مرحله اول — آماده‌سازی سرور ایران

دستور نصب یک‌خطی را روی سرور ایران وارد کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/MasterALiReza/Ox-Tunnle/main/install.sh)
```

پس از اتمام نصب، برای ورود به منوی مدیریت ابزار دستور زیر را تایپ کنید:

```bash
sudo ox-tunnle
```

### 1️⃣ نصب زیرساخت‌ها و سرویس‌ها

از منو گزینه زیر را انتخاب کنید:
```
5) Install / Complete Setup
```
این گزینه پیش‌نیازها را نصب کرده و سرویس استاندارد سیستم (Systemd Service) را ثبت می‌کند.

---

### 2️⃣ ایجاد پروفایل تانل (سرور ایران)

```
1) Create/Update profile
2) IRAN Server
```

- **انتخاب اسلات (1 تا 10):** شماره اسلات دلخواه را انتخاب کنید (مثلاً اسلات ۱ با نام `ir1` شناخته خواهد شد).
- **وارد کردن Bridge Port:** پورت اصلی ترافیک (پیش‌فرض: `7000` - در هر دو سرور باید یکسان باشد).
- **وارد کردن Sync Port:** پورت همگام‌سازی (پیش‌فرض: `7001` - با Bridge متفاوت و در هر دو سرور یکسان باشد).
- **حالت AutoSync:** با وارد کردن `y` حالت همگام‌سازی خودکار پورت‌های شنود را فعال کنید.
- **توکن امنیتی (Secret Token):** یک کلمه عبور قوی وارد کنید یا برای تولید اتوماتیک کلید امنیتی قدرتمند کلید Enter را بزنید. *(توکن نمایش داده شده را کپی کنید تا در سرور خارج وارد نمایید).*

# 🔵 مرحله دوم — آماده‌سازی سرور خارج (EU)

اسکریپت نصب را روی سرور خارج اجرا کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/MasterALiReza/Ox-Tunnle/main/install.sh)
```

منو را باز کنید:
```bash
sudo ox-tunnle
```
گزینه‌های زیر را به ترتیب انتخاب کنید:
```
5) Install / Complete Setup
1) Create/Update profile
2) EU Server
```
- **همان شماره اسلات** انتخاب شده در سرور ایران را انتخاب کنید (مثلاً اسلات ۱ - `eu1`).
- **آی‌پی سرور ایران** را دقیق وارد کنید.
- **Bridge Port** و **Sync Port** را دقیقاً مطابق با سرور ایران وارد کنید.
- **توکن امنیتی** (که در سرور ایران ساخته شد) را عیناً وارد نموده و Enter را بزنید.

# ▶️ مدیریت و پایش سرویس‌ها

شما می‌توانید اسلات‌های فعال را هم از طریق منوی تعاملی و هم با استفاده از فرامین استاندارد سیستم‌عامل (`systemctl`) کنترل کنید:

## مدیریت از طریق منو:
```
2) Manage tunnel (select slot)
→ انتخاب نوع سرور (IRAN یا EU)
→ انتخاب شماره Slot
→ 2) Start / Restart
→ 5) Status / View Logs
```

## مدیریت مستقیم با Systemd لینوکس (روشن‌تر و سریع‌تر):
```bash
# روشن کردن یا استارت اسلات موردنظر (مثلاً اسلات 1 سرور خارج یا ایران)
systemctl start ox-tunnle@eu1
systemctl start ox-tunnle@ir1

# مشاهده وضعیت زنده و تایید فعال بودن سرویس
systemctl status ox-tunnle@ir1

# توقف و بستن تانل
systemctl stop ox-tunnle@ir1

# مشاهده زنده لاگ‌های عملکرد تانل
journalctl -u ox-tunnle@ir1 -f
```

# 🔐 امنیت و مکانیزم‌های دفاعی

در نگارش جدید، ارتقاهای سطح سرور زیر تعبیه شده‌اند:
- **احراز هویت Challenge-Response:** به جای ارسال مستقیم پسورد، در هر نشست ترافیک یک عدد تصادفی (Nonce) ۱۶ بایتی با الگوریتم قدرتمند HMAC-SHA256 بررسی می‌شود تا امکان تکرار بسته‌ها (Replay Attack) توسط فایروال‌های بازرسی‌کننده از بین برود.
- **دفاع در برابر اسکنرهای پورت:** در صورتی که ابزار ناشناس به پورت Bridge یا Sync متصل شود و حداکثر تا ۳ ثانیه توکن HMAC صحیح را ارسال نکند، سوکت بدون هیچ پاسخی بسته (Drop) می‌شود.
- **کنترل خودکار منابع:** اندازه بافر استخر کانکشن‌ها متناسب با RAM و محدودیت FD سرور تنظیم می‌شود تا از هنگ کردن سیستم‌عامل در ترافیک‌های سنگین ممانعت کند.

# ⚡ تنظیمات پیشرفته و متغیرهای محیطی

موتور اصلی (`ox-tunnle.py`) می‌تواند از طریق فلگ‌های Command Line و متغیرهای لینوکسی کنترل شود:

```bash
# اجرای دستی از خط فرمان
python3 /usr/local/bin/ox-tunnle.py --role ir --bridge-port 7000 --sync-port 7001 --secret YOUR_SECRET_KEY

# متغیرهای بهینه‌سازی
export OXTUNNEL_POOL=256                           # تغییر اندازه استخر اتصالات
export OXTUNNEL_LOG=/var/log/ox-tunnle/engine.log   # فعال‌سازی لاگ در فایل با مکانیزم چرخش خودکار
```

# 🛠 عیب‌یابی و بررسی خطاهای شبکه

- **بررسی پورت‌های شنود (Listening) در ایران:**
  ```bash
  ss -lntp | grep python3
  ```
- **تست برقرار بودن شبکه بین خارج و ایران:** (توسط سرور خارج اجرا شود)
  ```bash
  nc -zv IR_SERVER_IP 7000
  nc -zv IR_SERVER_IP 7001
  ```
- **بررسی ۵۰ لاگ اخیر سرویس در صورت قطعی:**
  ```bash
  journalctl -u ox-tunnle@ir1.service -n 50 --no-pager
  ```
